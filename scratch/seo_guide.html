EraserPro AI: Step-by-Step SEO & Blog Writing Integration Guide

Welcome! This guide outlines the exact workflow for writing SEO-optimized articles, managing the static site architecture, adding metadata, and deploying blog updates to the live production site of EraserPro AI (hosted at bg-eraser-pro.com).

Site Architecture Note: EraserPro AI is built as a high-performance static HTML/CSS/JS web application. There is no server database. Every new blog post will be created as a static HTML file inside a /blog/ subdirectory. This structure guarantees lightning-fast page loads (improving LCP) and makes it extremely easy for search engines like Google to index and crawl your articles.

Step 1: Accessing the Codebase

To begin working on the website, request collaborator access to the GitHub repository. Once added, follow these steps to set up your environment:

  1. Clone the Repository: Open your terminal and run: 
    git clone https://github.com/yahya0347/BGR-Pro.git
cd BGR-Pro
  2. Run a Local Preview Server: To view your changes in real-time before deploying, start a local server: 
    python3 -m http.server 8080
    Now open your browser and navigate to http://localhost:8080.

Step 2: Creating a New Blog Article

All blog articles are stored in a subdirectory named /blog/. Follow this structure to add a post:

  1. Create a subfolder structure like blog/how-to-remove-image-watermarks.html. Use short, lowercase, hyphenated URL slugs containing your main target keywords (e.g. how-to-remove-bg-free.html).
  2. Use the Shared Template: Copy the header, footer, styles, and font links from the main index.html to ensure that your blog page looks consistent with the main site branding (off-white premium theme).
  3. Add a wrapper container for your article content to make it readable: 
    <article class="blog-container">
  <h1 class="blog-title">How to Remove Watermarks from Photos Without Quality Loss</h1>
  <div class="blog-meta">Published on June 15, 2026 by SEO Expert</div>
  
  <p>Start writing your content here...</p>
</article>

Step 3: On-Page SEO Optimization Guidelines

To rank for high-value terms (e.g. "free AI background eraser", "remove watermarks online"), ensure every article conforms to the following standards:

  • Title Tag: Place a unique title tag in the head. Keep it between 50-60 characters and put the primary keyword at the beginning: 
    <title>Remove Watermarks Online Free (No Quality Loss) - EraserPro AI</title>
  • Meta Description: Write an engaging description (140-160 characters) to boost Click-Through Rate (CTR): 
    <meta name="description" content="Erase watermarks, logos, and text from your images instantly with our free AI tool. No software installation required. Get clean, high-quality photos now.">
  • Heading Hierarchy: Use exactly one <h1> tag per page for the article title. Organize subsections using structured <h2> and <h3> tags.
  • Image Alt Attributes: Always provide descriptive alt text containing keywords for any images in the blog: 
    <img src="images/watermark-eraser-example.jpg" alt="AI watermark eraser tool interface cleaning photo">
  • Internal Link Building: Proactively link back to the home page tools using keyword anchor text (e.g., "use our free AI background remover to transparentize your PNGs"). This distributes page authority and boosts the rankings of the core tool workspace.

Step 4: JSON-LD Blog Schema Markup

To help search engines display rich snippets, insert structured JSON-LD data inside the <head> of the article:

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BlogPosting",
  "headline": "How to Remove Watermarks from Photos Without Quality Loss",
  "image": "https://bg-eraser-pro.com/blog/images/cover.jpg",
  "author": {
    "@type": "Person",
    "name": "SEO Expert"
  },
  "publisher": {
    "@type": "Organization",
    "name": "EraserPro AI",
    "logo": {
      "@type": "ImageObject",
      "url": "https://bg-eraser-pro.com/stripe_product_logo.png"
    }
  },
  "datePublished": "2026-06-15",
  "description": "A step-by-step guide to erasing watermarks, logos, and text overlays from images using AI reconstruction techniques."
}
</script>

Step 5: Testing and Deployment

Once the blog post is finalized and styled, verify and push it to production:

  1. Local Verification: Run your local server and inspect the layout on both desktop and mobile viewports. Check for any broken links, images, or spelling errors.
  2. Git Commit: Commit the changes to your local git branch: 
    git add .
git commit -m "Add blog article: How to remove watermarks without quality loss"
  3. Push to GitHub: Pushing your commits will automatically trigger Netlify's continuous integration if connected: 
    git push origin main
  4. Manual Netlify Deploy (If continuous integration is not set up): 
    npx netlify deploy --dir=.
# promoting the deploy ID to production:
npx netlify api restoreSiteDeploy --data '{ "site_id": "c88981c4-43ce-41b1-8919-72ee4d6dec98", "deploy_id": "<deploy_id>" }'
Best Practice Tip: Keep style modifications scoped strictly to a separate blog.css or inline style blocks within the article, and avoid editing the core styles.css to prevent breaking the editor workspace views.
