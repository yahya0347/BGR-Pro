Why Does My Transparent PNG Show a Black Background?

A transparent PNG shows a black background when the app or viewer you're using doesn't support transparency and renders empty pixels as solid black instead of see-through — the file itself is fine, it's how it's being displayed. This is common in older image viewers, some mobile galleries, and certain design tools with default canvas settings, and it's fixed by opening the file in an app that properly supports PNG transparency, like a browser, Photoshop, or Canva.

Why This Happens

  • PNG transparency is stored as an "alpha channel" — pixels with no color assigned.
  • Not every app knows how to render that channel — some default to showing it as black, others as white, and only proper viewers show the standard gray-and-white checkerboard pattern.
  • This is especially common when: opening the file in Windows File Explorer thumbnails, pasting into certain design or presentation software, or viewing on some older Android/Windows photo viewers.
  • It's a display issue, not a broken file — the same PNG will look transparent again the moment it's opened somewhere that handles transparency correctly.

How to Fix It (By Where You're Seeing It)

  1. In a browser: Drag the file directly into a new Chrome or Safari tab — browsers render PNG transparency correctly, so this confirms the file itself is fine.
  2. In Windows File Explorer: Switch the folder view or thumbnail settings, or open the file in Photos/Paint instead of relying on the thumbnail preview.
  3. In Photoshop or a design tool: Make sure you're placing the image on a layer, not a flattened background — pasting onto a "Background" layer forces a solid fill behind transparent pixels.
  4. On mobile: Open the file in a photo editor or browser rather than a basic gallery app, since some default galleries don't render alpha transparency.
  5. If none of that works: Re-download the PNG from the original source (in case the file got re-saved or converted to JPEG somewhere along the way, which strips transparency entirely).

How to Confirm Your PNG Actually Has Transparency

  • Open the file in a browser or in Preview (Mac) / Photos (Windows) — both render transparency as a checkerboard or true see-through.
  • If it's genuinely see-through there, the file is correct and the black background was just a display quirk somewhere else.
  • If it's still black or shows a solid color in every app you try, the file may have been saved as JPEG at some point (JPEG doesn't support transparency at all) — re-export or re-download as PNG.

Frequently Asked Questions

Is my PNG file broken if it shows a black background?

No — this is almost always a display issue with the app or viewer, not a problem with the file itself.

Why does my transparent PNG look fine in one app but black in another?

Different apps handle the alpha (transparency) channel differently — some render it correctly as see-through, others default to black or white when they don't support it.

Does this happen with JPEG files too?

No — JPEG doesn't support transparency at all, so a JPEG will always have a solid background. If your image shows black consistently everywhere, check that it wasn't accidentally saved or converted to JPEG.

How do I check if a PNG is actually transparent?

Open it in a web browser or your device's built-in photo viewer (Preview on Mac, Photos on Windows) — these correctly render transparency as a checkerboard pattern.
